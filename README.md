### 📂 Featured projects
**[Excel Report Automation](https://github.com/Sossa300/excel-report-automation)** – turns a folder of
messy Excel/CSV exports into one clean, formatted Excel report with pivot tables and charts.
Command line tool plus Streamlit web UI, built with pandas and openpyxl, tested with pytest.
▶ **[Live demo](https://sossa300-excel-report.streamlit.app/?demo=1)**

**[Price Alert Bot](https://github.com/Sossa300/price-alert-bot)** – Telegram bot that watches
product pages and messages you when a price drops, an item is back in stock or your target price
is reached. Chat commands, scheduled checks, SQLite storage, token kept in `.env`, 85 tests
without network (python-telegram-bot).

**[Book Price Scraper](https://github.com/Sossa300/book-price-scraper)** – polite web scraper that
collects prices, ratings and stock across all pages of a shop and exports them to CSV, Excel,
JSON or SQLite. CLI plus Streamlit dashboard, 60 tests.

**[ICT Analysis Tool](https://github.com/Sossa300/ict-analysis-tool)** – multi-timeframe market
analysis with a Streamlit dashboard, interactive Plotly charts, backtesting of 27 methods and
154 automated tests.
